The Chart Design tab of the Spreadsheet Editor allows managing the appearance and layout of the selected chart. To learn how to insert a chart, please refer to this article.

The corresponding window of the Desktop Spreadsheet Editor:

Using this tab, you can:

  • manage chart elements such as the chart title, data labels, and legend,
  • select the chart data range and manage legend entries and axis labels,
  • swap the chart rows and columns,
  • choose a chart design from the available presets,
  • change the chart type (Column, Line, Pie, and others),
  • access advanced chart settings,
  • adjust the chart width and height manually,
  • lock the aspect ratio when resizing.
